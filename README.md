# Deliveryfone Trade OS

Sistema web para gestão de operações de varejo, com foco em processos de trade-in, avaliação de dispositivos usados, vendas e gestão operacional de lojas.

## Sobre o projeto

O Deliveryfone Trade OS surgiu a partir de problemas e necessidades observados em operações reais de varejo de telefonia.

O sistema busca centralizar processos relacionados à operação comercial, incluindo consulta e gestão de produtos, registro de vendas, avaliação de dispositivos usados, simulações e fluxos de aprovação.

O projeto também é utilizado como ambiente prático de estudo e evolução técnica, com foco na compreensão da arquitetura, regras de negócio, banco de dados e desenvolvimento web.
